# Excavación en el Estanque de Tormentas · Sprint 2

A este juego le faltan los ajustes de cada persona del grupo, en `juego/ajustes.py`.
Rellenadlo siguiendo el manual `Butarque_Sprint_2.pdf`.

## Arrancarlo

Desde el terminal de Visual Studio Code, dentro de esta carpeta:

```
python main.py
```

En Linux, `python3 main.py`.

Hasta que `ajustes.py` esté completo, sale un `NameError`. Leedlo de abajo arriba:
la última línea dice qué nombre falta.

## Qué hay en la carpeta

```
excavacion_S2/
├── main.py            ← se arranca con este
├── datos/fosiles.csv  ← los fósiles del juego (no tocar)
└── juego/
    ├── ajustes.py     ← EL QUE TENÉIS QUE RELLENAR
    ├── principal.py   ← dibuja el juego (no tocar)
    ├── excavacion.py  ← reglas del juego (no tocar)
    └── datos.py       ← lee los fósiles (no tocar)
```
